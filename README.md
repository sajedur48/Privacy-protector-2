# 🛡️ Privacy Protector - AI Redaction Tool

An intelligent system that automatically detects and redacts sensitive information from unstructured text data while preserving readability and context.

## 🚀 Features

- **8 Entity Types**: PERSON, LOCATION, EMAIL_ADDRESS, IP_ADDRESS, PHONE_NUMBER, CREDIT_CARD, DATE_TIME, URL
- **Dual Modes**: Redact (remove) or Mask (replace with [ENTITY_TYPE])
- **Hybrid AI**: Combines spaCy NLP with rule-based regex patterns
- **Web UI**: Streamlit-based evaluation interface
- **Performance Metrics**: Levenshtein similarity scoring
- **Export Results**: Download redacted text and entity reports
